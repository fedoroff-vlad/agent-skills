# onboard-repo

Делает так, чтобы у opencode был точный контекст ЭТОЙ репы в `AGENTS.md` в её корне
(opencode читает его поверх глобального). Два режима — по наличию файла.

## Правила (общие для обоих режимов)
- **Не выдумывать.** Карта модулей и команды сборки — только из `scripts/scan_modules.py`
  (парсит реальные pom.xml). Глоссарий — только из README/доков репы; чего нет — помечай
  `TODO`, не сочиняй расшифровки.
- **Локально, не в VCS.** Файл личный → добавить `AGENTS.md` в `.git/info/exclude`
  (не трогая общий `.gitignore`), чтобы случайно не закоммитить.
- **Минимальные правки.** Не перезатирать то, что владелец вписал руками (особенно глоссарий).
- **SCOPE:** пишем только `<repo>/AGENTS.md` и `.git/info/exclude`. Больше ничего.

## Режим A — Bootstrap (файла `AGENTS.md` в корне нет)
1. Запусти грунт-скрипт из корня репы:
   ```powershell
   python <путь-скилла>\scripts\scan_modules.py .
   ```
   Возьми из вывода готовую таблицу модулей и блок команд сборки — как есть.
2. Прочитай корневой `README*` и `docs/` (если есть) → вытащи домен-термины/аббревиатуры
   для глоссария. Не уверен в значении — строка с `TODO`.
3. Создай `<repo>/AGENTS.md` со структурой: заголовок → **Карта модулей** (из п.1) →
   **Сборка и тесты** (из п.1) → **Доменный глоссарий** (из п.2) → **Gotchas** (пусто +
   строка-подсказка «пополняется по ходу»). Держи файл коротким.
4. Локальный игнор:
   ```powershell
   Add-Content .git\info\exclude "AGENTS.md"
   ```
5. Покажи файл, попроси владельца дозаполнить глоссарий/ответственности модулей.

## Режим B — Enrich (файл уже есть)
1. **Дрейф карты модулей:** перезапусти `scan_modules.py`, сравни с текущей таблицей.
   Появились/исчезли модули → обнови только таблицу (остальное не трогай).
2. **Новые gotchas:** добавь в секцию `## Gotchas` одну строку на грабли (симптом → как
   обойти). Не дублируй существующие.
3. **Глоссарий:** дополняй новыми терминами; вписанное руками не переписывай.
4. Покажи diff, ничего не коммить.

## Органическое обогащение (без явного вызова)
Во время обычной работы, наткнувшись на repo-specific грабли (квирк сборки, пин версии,
кодировка, proto-нюанс) или на устаревшую карту модулей — допиши строку в `<repo>/AGENTS.md`
сам (working tree, покажи в diff). Это и есть «самообогащение» — см. правило в глобальном
AGENTS.md.
